// jīvanmuktikalyāṇam nallādhvariviracitam //

// prathamo 'ṅkaḥ //

bhadrākāraparigrahocitamadārambhapriyaṃbhāvukāḥ

svīkurvañ śubhavāsanāḥ katicid apy āśāpariṣkāriṇīḥ /

śrutyantābhyasanair alivyatikarād ātmānam unmocayan

sa śrīmān kṛpayā mahāgaṇapatiḥ puṣṇātu niḥśreyasam //

JMK_1.1

(nāndyante)

sūtradhāraḥ

tādātmyena nirantarālamilitāṃ gaurīṃ vihārecchayā

vismṛtyātha tayā viyojita ivātanvaṃs tadanveṣaṇam /

senānyā bhagavan bhavāny api bhavān evety anūdbodhitas

tallābhād iva nirvṛto diśatu vaḥ śreyo 'rdhanārīśvaraḥ //

JMK_1.2

(iti puṣpāñjaliṃ vikīrya, nepathyābhimukham avalokya,) ārye, itas tāvat /

(praviśya)

naṭī

ajja, ïamhi / [ārya, iyam asmi /]

sūtradhāraḥ

ārye, adya khalu bhagavato madhyārjunaprabhor yātrāpratyupasthitaiḥ śamadamapradhānair brahmaniṣṭhair ādiṣṭo 'smi sāmājikair adhyātmakathānubandhabandhuraṃ kim apy apūrvaṃ nāṭakaṃ nāṭayitavyam iti / tad anucintyatāṃ tvayā tathāvidhaṃ nāṭakam /

naṭī

ajja, kiṃ vi me ṇa paḍihāi / [ārya, kim api me na pratibhāti /]

sūtradhāraḥ

ayi vismaraṇaśīle, tvam ajaivāsi prakṛtyā /

naṭī

(sakrodham) jai evvaṃ tado ajjassa aṇurūvā bhavissaṃ / [yady evaṃ tata āryasyānurūpā bhaviṣyāmi /]

sūtradhāraḥ

(sakrodhāvegam) mugdhe, prakṛtyāham api yady ajaḥ syām tarhi tadanurūpa ācāraḥ pakṣe tvatparityāgarūpa eva paryavasyed iti mahad aniṣṭam āpadyeta / tathā khalv ajānām ācāro dṛśyate /

ekām ajāṃ lohitaśuklakṛṣṇāṃ

bahvīḥ prajāḥ svānuguṇāḥ sṛjantīṃ /

eko hy ajas tām anuśeta eva

jahāti enām aparo 'nubhuktām //

JMK_1.3
naṭī

bhuttabhoaṃ maṃ ujjhia aṇṇāe ka e vi kaṇṇāe saṃgadua ṇivvudo hodu ajjo / [bhuktabhogāṃ mām ujjhitvā 'nyayā kayāpi kanyayā saṃgatya nirvṛto bhavatv āryaḥ /] (iti sāṭopaṃ parāvartate)

sūtradhāraḥ

(sānunayaṃ haste gṛhītvā) ayi sadasadvilakṣaṇe, vācārambhaṇamātra eva prapañco na paramārthaḥ / tad ehi, mā nivartasva / nartitavyaṃ nāma tvayā yāvat pratibhāsaṃ prārabdhānusāreṇa / tatas tu paraṃ svata eva parāvartiṣyase /

naṭī

(saprasādaunmukhyam) ajja, mae kiṃ ṇañcidavvaṃ? [ārya, mayā kiṃ nartitavyam?]

sūtradhāraḥ

jīvanmuktikalyāṇaṃ nāma nāṭakam, yasya kaviḥ subhadrāpariṇayaśṛṅgārasarvasvacittavṛttikalyāṇādvaitarasamañjaryādyanekaprabandhanibandhanābhinandanīyaḥ śrībālacandramakhindranandano nallādhvarī /

naṭī

ajja, sumarāvidamhi / visumaraṇakido uṇa maha avarāho marisidavvo / [ārya, smāritā 'smi / vismaraṇakṛtaḥ punar mamāparādho marṣitavyaḥ /]

sūtradhāraḥ

astu nāmedam / prastūyatāṃ saṃgītakam / saṃprati hi,

śāradānugrahavaśād viśadīkṛtamānasāḥ /

haṃsābhyudayaśaṃsinyo vāsarāṇāṃ vibhūtayaḥ //

JMK_1.4
naṭī

dāṇiṃ paḍippahādaṃ sujjāloapphuḍīkidaṣpasirī /

ṇa khu sā rājīvatadī khamadi bhamaralakkhaṇappaparihūdiṃ //

JMK_1.5

idānīṃ pratiprabhātaṃ sūryālokasphuṭīkṛtātmaśrīḥ /

na khalu sā rājīvatatiḥ kṣamate bhramaralakṣaṇātmaparibhūtim //

sūtradhāraḥ

kavir atimanojñasūktiḥ kathā jagatpāvanī vayaṃ kṛtinaḥ /

pariṣad iyaṃ guṇaniṣṭhā bhavyasya vidheḥ prasādavibhavo 'yam //

JMK_1.6

(nepathye)

aye bharatakulaśekhara, vidhiprasādavibhava iti māṃ nirdiśañ ślāghanīyo 'si /

codanātmā vidhis tasya prasādo janako mama /

vidhiprasādavibhavas tasmād aham udāhṛtaḥ //

JMK_1.7
sūtradhāraḥ

(smṛtim abhinīya) katham eṣa praviṣṭa eva bhāvo jīvāmātyasya ramaṇīyacaraṇasya bhūmikām ādāya raṅgamaṇḍapam / ārye, tadā āvām apy anantarakaraṇīyāya sajjībhavāvaḥ / (iti niṣkrāntau)

// prastāvanā //

(tataḥ praviśati ramaṇīyacaraṇaḥ)

ramaṇīyacaraṇaḥ

vidhigocarakarmanirmitatvād

vimalo 'haṃ sakalābhilāṣapātram /

upajīvyatayā tataḥ pareṣāṃ

prathitaḥ prāthamikaḥ svayaṃ samarthaḥ //

JMK_1.8

api ca,

svargādinaśvaraphalānabhisaṃdhibandha-

nirvyūḍhayā bhagavadarthatayānvito yaḥ /

tasmān nisargamahataḥ śubhakarmarāśer

jātasya me kim itareṇa guṇottareṇa //

JMK_1.9

kiṃ ca,

anenaivānubhāvena mayā labdhā mahonnatā /

sattvaśuddhir iti khyātā kanyā kalmaṣahāriṇī //

JMK_1.10

(praviśya)

sattvaśuddhiḥ

āṇavedu ajjo jaṃ mae aṇuciṭṭhiadu / [ājñāpayaty āryo yan mayā 'nuṣṭhīyatām /]

ramaṇīyacaraṇaḥ

vatse, kim anyat? devasya tvayā sāhāyakam ācaritavyam /

sattvaśuddhiḥ

ko so devo? [kaḥ sa devaḥ?]

ramaṇīyacaraṇaḥ

so 'yaṃ yaḥ svayam advitīyapadavīsāmrājyadhauraṃdharīm

āsādya pratitiṣṭhati sma mahimākāre svabhadrāsane /

yaś ca vyādhakule vasann iva mahīpālātmajo vyādhatāṃ

jīvatvaṃ gatavān vimohavaśataḥ svasmāt padād bhraṃśitaḥ //

JMK_1.11
sattvaśuddhiḥ

ajja, kiṃ patthudaṃ tassa devassa / [ārya, kiṃ prastutaṃ tasya devasya /]

ramaṇīyacaraṇaḥ

pāṇigrahaṇamahotsavaḥ /

sattvaśuddhiḥ

ajja, atthi khu tassa puḍhamo paḍiggaho devī, yā buddhi tti andakaraṇam tti maṇaṃ tti cittaṃ tti a bhaṇïadi / [ārya, asti khalu tasya prathamaḥ pratigraho devī, yā buddhir ity antaḥkaraṇam iti mana iti cittam iti ca bhaṇyate /]

ramaṇīyacaraṇaḥ

saṃprati tasyāṃ vairasyenopajātajihāso devaḥ /

sattvaśuddhiḥ

haddhi haddhi, chāādavāṇaṃ vïa samaṇïadāṇaṃ vi tāṇaṃ īriso dasāpariṇāmo [hā dhik, hā dhik / chāyātapayor iva samaniyatayor api tayor īdṛśo daśāpariṇāmaḥ /]

ramaṇīyacaraṇaḥ

vatse, chāyātapayor iveti viṣamo dṛṣṭāntaḥ /

chāyaiṣā punar ātapo 'yam iti ca spaṣṭaṃ pratītātmanor

anyonyaṃ vyatiṣaktayor api tayor bhedaḥ sukhaṃ gṛhyate /

anyonyātmakayor anādisamayād anyonyatāddharmyayor

buddhir jīva iti dvayor api tayor bhedagraho durlabhaḥ //

JMK_1.12
sattvaśuddhiḥ

ajja, īrisī a devī kīsa deveṇa virasadāe goarīkidā? [ārya, īdṛśī devī kasmād devena virasatāyā gocarīkṛtā?]

ramaṇīyacaraṇaḥ

yatas tatsamgamaprabhṛti sukham iti kiṃcin na jānāti devaḥ / tathā hi,

rāgadveṣakaṣāyitasvavapuṣā buddhyā samāliṅgitaḥ

puṇyāpuṇyamayeṣu karmasu tato mohāt pravṛttaḥ svayam /

dehādyātmatayā 'tha karmajanitaṃ svargādirūpaṃ phalaṃ

bhuñjāno janihāniduḥkhajaladher āvarta āvartate //

JMK_1.13

uktaṃ ca māṃ prati garbhagṛhaṃ praviṣṭena devena,

saṃsārādhvani saṃkaṭe niravadhau tāpatrayopaplute

yātāyātakṛtā yayā mama cirād ātmettham āyāsyate /

asmād garbhagṛhād bahir yadi vinirgamyeta kiṃcin mayā

saiṣā 'narthakarī tadaiva sahasotsṛṣṭeti niścīyatām //

JMK_1.14

iti

sattvaśuddhiḥ

haddhi, haddhi / sāhasavvavasāo devo / ajja, kahaṃ so gabbhadharaaṃ paviṭṭo? iṭhṭhādikāridāe dhūmādimaggeṇa candaloaṃ gado tti khu suṇijjaï / [hā dhik, hā dhik / sāhasavyavasāyo devaḥ / ārya, kathaṃ sa garbhagṛhaṃ praviṣṭaḥ? iṣṭādikāritayā dhūmādimārgeṇa candralokaṃ gata iti khalu śrūyate /]

ramaṇīyacaraṇaḥ

vatse, śrūyatām,

gatvā candramasaṃ vibhūtyanubhavāt prakṣīṇapuṇyas tato

bhūloke 'vataran kapūyacaraṇaṃ jitvā mayā ''lambitaḥ /

śraddhādyāhutipañcakena ca pathā yoniṃ gato brāhmaṇīṃ

garbhāgāram anupraviśya daśame māse tato nirgataḥ //

JMK_1.15

saṃprati ca,

indriyahayaṃ manomayaraśmicayaṃ buddhisārathisanātham /

deharatham āsthito 'yaṃ devo viṣayāṭavīṣu paryaṭati //

JMK_1.16
sattvaśuddhiḥ

kahaṃ idaṃ vi evvaṃ ṇāma / [katham idam apy evaṃ nāma /]

ramaṇīyacaraṇaḥ

vatse, anyad apy asti kāraṇaṃ devījihāsāyāṃ devasya, yat purāṇajyotirvidām anukramaṇam / yathā,

buddhityāgena devasya svapadaprāptir iṣyate /

buddhityāgaś ca viśvātiśāyidārāntarānvayāt //

JMK_1.17

iti

sattvaśuddhiḥ

ajja, kā uṇa kaṇṇā tārisī jāe joeṇa devassa sapadappattī vavadisijjaï / [ārya, kā punaḥ kanyā tādṛśī, yasyā yogena devasya svapadaprāptir vyapadiśyate /]

ramaṇīyacaraṇaḥ

adyāpi nāvadhāryate / preṣitas tāvan mayā tādṛśakanyānveṣaṇāyāpātabodho [nā]mādhuniko devānucaraḥ /

sattvaśuddhiḥ

kahaṃ vïa edaṃ ghaḍijjaï? [katham ivaitad ghaṭiṣyate?]

ramaṇīyacaraṇaḥ

kiṃ tādṛśī kanyaiva durupalambheti tathā bravīṣi, āho svid upalabdhāpi devasya durlabheti?

sattvaśuddhiḥ

taha taha a / [tathā tathā ca /]

ramaṇīyacaraṇaḥ

ayi vatse,

devo 'yaṃ svapadāc cyutaḥ kila kuto bhūyo 'pi tasyodayaḥ

śreyo vā tad idaṃ pumarthapariṣanmūrdhābhiṣiktaṃ kutaḥ /

ity evaṃ yadi manyase hṛdi tadā mithyaiva te niścayas

tat tasya kva gataṃ padaṃ kva nu gato devaḥ sa vā saṃprati //

JMK_1.18

paraṃ tu mocanīyo devaḥ pāśabandhād ajñānavarmaṇa aindrajālikasya / ya eṣaḥ,

vikṣepāvṛtiśaktimāñ jaḍamayo mohātmako duḥkhabhūr

asthānapratibimbataḥ prakaṭayann ātmānam apy anyathā /

ākāśānilahavyavāhasalilakṣoṇyātmabhiḥ pañcabhir

bhūtair ātanute nijāṃ pariṇatiṃ pañcīkṛtiprakramaiḥ //

JMK_1.19
sattvaśuddhiḥ

ajja, kiṃ so jo devīe tādo tti suṇijjaï / haddhi haddhi / dujjao khu so / [ārya, kiṃ sa yo devyās tāta iti śrūyate / hā dhik, hā dhik / durjayaḥ khalu saḥ /]

ramaṇīyacaraṇaḥ

(saroṣam) vatse, kim ucyate durjaya iti /

ātmasvāminam indrajālavidhinā pāśena badhnāti yaḥ

paśyainaṃ paśukalpam alpadhiṣaṇaṃ baddhvā padākramya ca /

chindan krandata eva tattvam asinā tasyāṅgakaṃ khaṇḍaśo

viśvagrāsaparasya tena mahato bhūtasya kuryāṃ balim //

JMK_1.20
sattvaśuddhiḥ

ajja, mā kuppa / arihi kāmādihiṃ karijjantasāhāao so saṅkidavvo tti taha mantemi / [ārya, mā kupya / aribhiḥ kāmādibhiḥ kriyamāṇasāhāyakaḥ sa śaṅkitavya iti tathā mantrayāmi /]

ramaṇīyacaraṇaḥ

kāmādayaḥ santu sahasram asya

sahāyabhūtā balinas tathāpi /

mahattarair ātmaguṇair bhṛtasya

mamāgrataḥ sthātum iha kṣamaḥ kaḥ //

JMK_1.21

(ubhau parikrāmataḥ)

ramaṇīyacaraṇaḥ

(nirūpya) katham ita eva devaḥ /

cirāya so 'yaṃ mṛgayāpravṛttaḥ pramattayā sārathibhāvabhājā /

vikṛṣyamāṇaḥ parito 'pi devyā guruvyathaḥ saṃmukham abhyupaiti //

JMK_1.22

(tataḥ praviśati yathānirdiṣṭo jīvaḥ, buddhiś ca rathena vibhavataś ca parivāraḥ |)

jīvaḥ

sa eṣa madhuraḥ svaro rucira eṣa rūpoccayaḥ

susaurabham idaṃ tv iyaṃ śiśiratā raso 'sāv iti /

itaḥ śravaṇam ekato nayanam anyato ghrāṇam

apy atas tvag api hanta māṃ rasanam agrataḥ karṣati //

JMK_1.23

devi, stimitagatayaḥ kriyantāṃ vājinaḥ / yataḥ,

dhāvanto viṣayeṣu sāṃpratam amī rathyās tava preraṇād

vyākarṣanti yathāyathaṃ tata itas tvām antato mām api /

āstāṃ tāvad idaṃ rathasya tu mahān āyāsayogaḥ paraṃ

na hy eṣa kṣamate śirīṣasumato 'py atyantam āpeśalaḥ //

JMK_1.24

katham eṣā madvacanam ākarṇya vighūrṇate bhūtāviṣṭeva / bhavatu, etān evāśvān pratisāntvayāmi /

śravaṇarasanaghrāṇatvaṅnetra hanta bhavanmukhaiḥ

sthitam abhimate vastuny astokasāhasavṛttibhiḥ /

alam alam itaḥ śrāntaṃ bhūyaḥ sukhena viramyatām

aham uparato mā mā karṣantu mām ayam añjaliḥ //

JMK_1.25

atha vā na durmadeṣv eteṣu sāntvavādaḥ kramate / hanta hanta,

ayaṃ śatāṅgaḥ parijarjarāṅgaḥ

pade pade śaṅkitabhaṅgam āste /

duṣṭā hayāḥ kaṣṭadaśā ca devī

kathaṃ nu kalyāṇapadaṃ bhajeyam //

JMK_1.26

(ākāśe) ramaṇīyacaraṇa, kvāsi bhoḥ kvāsi /

cirād etāvantaṃ samayam atighore bhavapathe

na kiṃ paryāpnoti bhramaṇam idam etāvad api me /

kiyantaṃ vā kālaṃ bhramayitum ito 'pi vyavasitaṃ

yathāsaṃkalpaṃ te bhavatu mama vā kiṃ pratihatam //

JMK_1.27
ramaṇīyacaraṇaḥ

(apasṛtya) vijayatāṃ devaḥ /

jīvaḥ

aye ramaṇīyacaraṇa,

ahaṃ bhrāmaṃ bhrāmaṃ krakacaparuṣe vai śrutipathe

pariśrānto nātaḥ padam api samartho vicalitum /

prabhutvaṃ mayy ārte prakaṭayasi kiṃ sāṃpratam idaṃ

tavopekṣāyā vā kimu samucito 'sāv avasaraḥ //

JMK_1.28
ramaṇīyacaraṇaḥ

dāsajane 'smin na sāṃpratam atimātraṃ vacanaṃ kalyāṇaśevadher devasya /

jīvaḥ

(sanirvedam) aticāriṇyā buddhyā saha saṃsarato mama kalyāṇe kā nyūnatā nāma / yathā,

rathyānā januṣaḥ parāṅmukhatayā nityaṃ pravṛttyunmukhān

bhūyaḥ preraṇakarmaṇā svayam api protsāhayantī muhuḥ /

svasthaṃ māṃ viṣameṣv amīṣu viṣayeṣv ākṛṣya cākṛṣya ca

bhrāmyantī kṛpayā hriyā ca rahitā nādyāpi viśrāmyati //

JMK_1.29
ramaṇīyacaraṇaḥ

deva, samakṣam eva devyāḥ katham evam ākrośaḥ kriyate /

jīvaḥ

eṣā saṃpraty ātmānam api na jānāti / paśya, paśya,

kāsārāntaram āsthitā jalajharī kulyā 'dhvanā niḥsṛtā

kedārābhigatā yathaiva hi tadākāreṇa saṃpadyate /

tadvad buddhir apīyam indriyacayadvārā bahir nirgatā

vyāpya svān viṣayāṃs tadākṛtigaṇenākāritā vartate //

JMK_1.30
ramaṇīyacaraṇaḥ

tarhi na khedāvasaro devasya /

dīrghā pradīpavalayasya marīcikeva

buddhir bahiḥ prasṛbharā viṣayān prayātu /

āruhya gacchatu bhavān api tāṃ pramātā

dolāvihṛtyanubhavena vinodyamānaḥ //

JMK_1.31
jīvaḥ

ko nāma vinodaḥ saṃsāraviṣavallarībījanyāsena pramātṛbhāvena / tathā hi,

pramātṛtvāveśe sati bhavati karmasv adhikṛtis tataḥ

kartṛtvaṃ syāt tadanu phalabhoktṛtvam api ca /

vimuktasyānena dhruvam akhiladuḥkhapraśamanaṃ

vimuktyarthopāyas tad anusaraṇīyaḥ prathamataḥ //

JMK_1.32
ramaṇīyacaraṇaḥ

(kiṃcid iva parāvṛtya) vatse sattvaśuddhe, ehi vandasva devam /

sattvaśuddhiḥ

(upasṛtya) deva, paṇamāmi / [deva, praṇamāmi /]

jīvaḥ

vatse, abhimatena yujyasva /

sattvaśuddhiḥ

ahimadā me devī / [abhimatā me devī /] (iti buddher aṅkam ārohati /)

jīvaḥ

aho, sattvaśuddhyāḥ saṃsparśamātreṇa prasannā devī prakṛtisthā ca saṃvṛttā /

buddhiḥ

vacche sattasuddhe, aviralaṃ maṃ parissajehi / [vatse sattvaśuddhe, aviralaṃ māṃ pariṣvajasva /]

sattvaśuddhiḥ

(tathā karoti)

buddhiḥ

vacche, ajjautto vi saṃbhāvïadu parisaṅgeṇa / [vatse, āryaputro 'pi saṃbhāvyatāṃ pariṣvaṅgeṇa /]

jīvaḥ

devi, mā maivam / yatas tvayi pariṣvaktāyām aham api pariṣvaktaprāya eva /

dhyāyatīva janas tv eṣa dhyāyantyām tvayi vallabhe /

calatīva calantyāṃ ca na svatantraḥ svayaṃ kvacit //

JMK_1.33
buddhiḥ

īriso ahiṇiveso assim jaṇammi ajjautassa / [īdṛśo 'bhiniveśo 'smiñ jane āryaputrasya /]

jīvaḥ

kim etad upacāraḥ /

nīrakṣīravad āvayor upanatā kālād bahor ekatā

viśleṣasya kathā kathaṃcid api na svapne 'pi saṃbhāvyate /

kiṃ ca tvadguṇasāratāmahimataḥ karteti bhokteti ca
